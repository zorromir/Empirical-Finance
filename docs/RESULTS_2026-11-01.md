# Public Python results — 1 November 2026

These figures come from a separate run of the public Python package. For the results from our submitted group study, see the [paper](Empirical_finance.pdf).

The sample is January 1927–December 2025 for calendar tests and July 1963–June 2026 for the other regressions.

## Calendar effects

Holm-adjusted p-values for the joint month-of-year Wald tests (HAC, 24 lags):

| Oil | Banks | Textiles | Toys | Retail |
| ---: | ---: | ---: | ---: | ---: |
| 0.0214 | 0.0214 | 0.0006 | 0.0087 | 0.0214 |

All five reject in the full sample. The [subperiod results](ROBUSTNESS_RESULTS_2026-11-01.md) show that the pattern changes over time.

## CAPM, FF5 and momentum

| Industry | CAPM adj. R² | FF5 adj. R² | FF5 alpha, %/month |
| --- | ---: | ---: | ---: |
| Oil | 0.3737 | 0.4531 | −0.1716 |
| Banks | 0.6286 | 0.7436 | −0.2382 |
| Textiles | 0.4612 | 0.6297 | −0.6156 |
| Toys | 0.5169 | 0.5940 | −0.5375 |
| Retail | 0.6811 | 0.7029 | +0.0568 |

FF5 raises adjusted R² in every industry, though the negative pricing errors remain. With the public code's HAC(24) and Holm correction, Textiles and Toys have significant FF5 alphas; Banks does not.

The momentum-factor intercept is about **0.71% per month** under the CAPM and **0.75%** under FF5.

## CAPM SDF

Two-step GMM gives `mu = 0.006370`, `c = 3.5704` and **J = 4.7784 (p = 0.3108)**. The report has J = 4.777 (p = 0.311).

## Differences from the paper

The submitted paper reports Banks as significant under FF5 using its original inference choices. The public implementation applies different HAC and multiple-testing settings; its significance results should not be treated as exact copies of the report. The original slope-restriction result is also not reproduced here.

The code uses Kenneth French data downloaded in November 2026. Source-file hashes are saved in the generated `outputs/manifest.json` so differences between data versions can be checked.

Run `python -m empirical_finance.cli` to regenerate the tables.
