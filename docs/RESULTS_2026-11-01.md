# Verified public-data run — 1 November 2026

These tables were generated by the independent code in this repository, using Kenneth French's public datasets available on **1 November 2026** (the data archives currently extend to September 2026). The historical evaluation windows deliberately stop at June 2026 for factor models and December 2025 for calendar tests.

The results are **in-sample statistical tests**, not trading performance. The original September 2026 five-person report remains a separate academic group product. This table is not a claim to have reproduced every table, model restriction or subperiod analysis in that report.

**Momentum:** Treating French's `Mom` as an existing long–short factor (not subtracting RF again), the CAPM intercept is approximately **+0.7141% monthly** (HAC p ≈ 7.54e-10), and FF5 approximately **+0.7495% monthly** (HAC p ≈ 7.20e-06). These are estimated model intercepts, not trade returns after frictions.

## CAPM stochastic discount factor: two-step GMM

The six-moment, two-parameter implementation uses five industry pricing moments and one market-mean condition; step two estimates an uncentered six-lag Bartlett/Newey–West moment covariance.

| Estimate | Value |
| --- | ---: |
| Market excess-return mean `mu` | 0.00637014 |
| SDF slope `c` | 3.570426 |
| Hansen J | 4.778368 |
| J-test degrees of freedom | 4 |
| J-test p-value | 0.310803 |

This fails to reject on the selected industry assets. It **does not validate the SDF** or address momentum-sorted portfolios.

## Comparison with the archived report

The independent calculation closely matches the previously documented GMM value (J ≈ 4.777 and p ≈ 0.311), the sign/significance of the FF5 Textiles and Toys alpha findings and the roughly 0.71%/0.75% momentum intercepts.

The publicly downloaded data vintage and implementation can change exact p-values: for instance, the previously recorded Banks Holm-adjusted FF5 alpha p-value was approximately 0.123, compared with **0.135** here. This is a comparison caveat, not a substantive reversal. No original group code or private archived data were uploaded for this release.

The public package still omits some original analyses, including subperiod calendar tests and the additional GMM slope-restriction test. Full numerical equivalence requires an explicit table-by-table comparison with the original source archive, with co-author publication permissions respected.
