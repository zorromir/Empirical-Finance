# Empirical Finance — independent reproducibility project

This repository is being built as a public, independently written research-code companion to a five-person MSc Empirical Finance group study at Tilburg University (2026). The original group report, source archive and student information are **not** published here.

The intended scope is reproducible analysis of public Kenneth French industry and factor returns, with explicit sample selection, HAC inference, multiple-testing corrections and model checks. Numerical results must not be treated as reproduced until the code runs on downloaded data and the output has been checked.

[Research context and previously audited findings](https://github.com/zorromir/zorromir.github.io/blob/main/projects/empirical-finance/README.md).
